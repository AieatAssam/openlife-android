## Security and provenance review

- The engine receives authenticated bytes from the C0 blob, never a provider
  URI, filename, or sender metadata. The original encrypted envelope and
  digest are not rewritten.
- OCR rows are derived and source-linked. OCR spans remain immutable;
  corrections are separate `USER` rows, and deletion explicitly removes OCR
  dependents before the Source row is removed.
- Boxes are retained only when ML Kit supplies one, mapped to
  `SOURCE_PIXELS`; absent confidence and regions remain absent. Unsupported or
  mixed scripts fail closed as `UNSUPPORTED_SCRIPT`.
- Text is rendered with ordinary Compose `Text` and no link/command dispatch.
  It is untrusted content, not an instruction channel.
- The bundled artifact contains Google ML Kit's transitive transport classes.
  OpenLife does not declare `INTERNET` or network-state access, removes those
  permissions from the merged manifest, excludes runtime model download, and
  uses no cloud or telemetry API of its own. This transitive footprint remains
  a release-review item before distribution.
